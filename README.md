# EMP Review

EMP Review supports structured assessment of scientific publications using the Evidential-Maturity Profile (EMP).

## Application versions

- **v0.17**: comprehensive review workflow, preserved at https://emp-review-mvp.dw1975.chatgpt.site
- **v0.18**: simplified workflow with one central claim, up to two contextual claims, and a short EMP profile per publication. Available separately at https://emp-review-focal.dw1975.chatgpt.site (access restricted to its owner).
